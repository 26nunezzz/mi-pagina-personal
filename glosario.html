Definiciones del glosario tecnico

  • Archivo: Un archivo es un elemento digital de la computadora donde se guardan documentos, imágenes, videos, música, etc.
  • Carpeta: Una carpeta es un espacio de la computadora que sirve para guardar y organizar archivos y otras carpetas, facilitando la búsqueda y el acceso a la información más rápido.
  • Extensión: La extensión es el final del nombre de un archivo que indica que tipo de archivo es y con qué programa se puede abrir.
  • CMD: Es una consola de Windows que sirve para interactuar con la computadora a través de comandos escritos.
  • Comando: Un comando es una instrucción que se le da a la computadora a través de la consola para que haga una acción específica.
  • Mkdir: mkdir es un comando que sirve para crear nuevas carpetas dentro de la computadora
  • Copy: es un comando que sirve para copiar archivos a otras carpetas.
  • Echo: También es un comando que sirve para mostrar un mensaje o texto en pantalla.
  • Script: Es un conjunto de comandos o instrucciones guardados en un archivo que se ejecutan de forma automática para realizar una tarea en específico.
  • Archivo .bat: Es un archivo que contiene una serie de comandos que se ejecutan automáticamente en la consola CMD.
  • Google Drive: Es un servicio en la nube que te permite guardar información, datos y archivos en internet para poder acceder fácilmente a ellos desde cualquier dispositivo.
  • Trabajo colaborativo: es una forma de trabajo en la que varias personas participan y colaboran en un mismo proyecto de forma conjunta, compartiendo tareas, archivos, documentos, etc. Permite que varias personas trabajen en un mismo documento al mismo tiempo y de distintos lugares.
  • Scratch: Es un programa que permite crear juegos utilizando bloques de instrucciones que se encastran entre sí, sin tener que escribir el comando. Te ayuda a aprender programación de una forma fácil y creativa.
  • Bloque: Es una instrucción gráfica utilizada en Scratch que sirve para realizar una acción específica.
  • Algoritmo: Un algoritmo es un conjunto de pasos ordenados que se siguen para resolver un problema.
  • Variable: espacio de memoria que puede cambiar su valor mientras se ejecuta el programa.
  • Condicional: Es una estructura de programación que permite tomar decisiones según se cumpla o no una condición.
  • Bucle: Es una estructura de programación que permite repetir una o varias acciones muchas veces hasta que se cumpla una condición.
  • PSeInt: Es un programa que sirve para aprender programación escribiendo algoritmos de manera fácil en pseudocódigo.
  • HTML: Es un lenguaje de marcado de etiquetas que se utiliza para crear la estructura de una página web. Organiza el contenido mediante títulos, párrafos, imágenes y enlaces.
  • Css: Es un lenguaje de diseño que sirve para definir el diseño, apariencia y estilo de una página.
  • JavaScript: Es un lenguaje de programación que se utiliza para que una página web sea interactiva. Permite que la página responda a las acciones del usuario, como hacer clic en un botón, mostrar mensajes o cambiar contenido sin tener que volver a cargar la página.
  • Etiquetas: Son instrucciones escritas entre los símbolos < > se utilizan en HTML para indicar cómo debe organizarse el contenido de una página.
  • Ide: Es un programa que reúne en un solo lugar las herramientas necesarias para programar de forma más fácil.
  • Visual studio code: Es un editor de código gratuito desarrollado por Microsoft que se utiliza para crear y editar programas y páginas web.
